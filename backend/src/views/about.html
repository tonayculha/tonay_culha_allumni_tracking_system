System Architecture & Design Governance

About the Project

Alumni Hub is a clean-room implementation of the Alumni Tracking System engineered with modular MVC layering, PostgreSQL persistence, defensive middleware guardians, and the WCAG 2.1 AA Collegiate Obsidian design system.

OpenAPI Docs Health Probe
Software Engineering

Layered MVC & Reliability

Routes delegate cleanly to dual controllers (human MVC views vs. pure JSON REST APIs), services enforce domain rules such as 409 Conflict duplicate-application prevention, and 404/5xx guardian middleware protects every request.

Brand & UI Craft

Collegiate Obsidian System

Governed by brand.md and DESIGN.md, all portals share verified HEX/HSL design tokens, a 4px/8px spacing grid, keyboard-accessible modals, and strict Helmet CSP compatibility with zero external CDN dependencies.

Runtime & Infrastructure

Technology Stack & Environment

Component Technology Specification & Role
Runtime Node.js v20+ LTS (multi-stage Alpine container with non-root execution)
HTTP Framework Express v4.19+ with Helmet CSP, CORS, monotonic request logger, and 404/5xx guardians
Database PostgreSQL 16-Alpine with transactional migrations, 1:N & N:M schemas, and named volume persistence
Containerization Docker Compose Multi-container orchestration gated by pg_isready health probes
Deployment Rule One-Command Rule Zero-touch deterministic startup via docker compose up --build
Design System CSS Custom Properties Shared /css/tokens.css & /css/style.css meeting WCAG 2.1 AA/AAA contrast
